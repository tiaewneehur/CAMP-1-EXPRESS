# Camp 1 Express — เว็บไซต์ + ระบบติดตามพัสดุ

เว็บบริษัทพร้อมระบบสมาชิกสำหรับ Camp 1 Express (ฝากสั่ง/ประมูล/ส่งทางเรือ ญี่ปุ่น → ไทย)
เขียนด้วย **PHP 8 + MySQL** ไม่ต้องติดตั้งไลบรารีเพิ่ม อัปโหลดขึ้น shared hosting (เช่น Hostatom) ได้ทันที

## ทำอะไรได้บ้าง

**หน้าเว็บสาธารณะ**
- หน้าแรก: บริการ ขั้นตอน เรท/ค่าส่ง เครื่องคิดค่าใช้จ่าย ราคาเหมาสินค้าชิ้นใหญ่ สินค้าที่ส่งได้ รูปโกดังจริง ช่องทางติดต่อ
- ภาษาไทย / อังกฤษ (ปุ่ม TH | EN)

**ลูกค้า**
- เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านที่แอดมินออกให้
- เข้าครั้งแรก **ระบบบังคับให้ตั้งรหัสผ่านใหม่เอง** และเปลี่ยนเองได้ทุกเมื่อ
- เห็นเฉพาะพัสดุในบัญชีตัวเอง: สถานะ 4 ช่วง (ญี่ปุ่น → เรือ → ไทย/ศุลกากร → ส่งถึงบ้าน), ประวัติทุกจุด, ชื่อเรือ, เลขตู้, ETA
- เลือกขนส่งในไทยเอง (Kerry, Flash, J&T, ไปรษณีย์ไทย, Ninja Van, BEST, Lalamove, รับเอง) + กรอกที่อยู่
- เห็นเลขพัสดุในไทยเมื่อส่งต่อแล้ว

**แอดมิน (หลังบ้าน)**
- สร้างบัญชีลูกค้า → ระบบสุ่มรหัสเริ่มต้น และสร้างข้อความพร้อมคัดลอกส่งทาง LINE
- รีเซ็ตรหัส / ปิด–เปิดบัญชี / แก้ชื่อ–เบอร์ / เพิ่มแอดมินคนอื่น
- ลงแทรคกิ้งให้ลูกค้าแต่ละยูส (ออกเลขอัตโนมัติ `C1YYMMxxxxx` หรือพิมพ์เลขเอง)
- อัปเดตสถานะทีละขั้น 10 สถานะ พร้อมสถานที่/หมายเหตุ, ลบสถานะที่ลงผิด
- ดูขนส่งที่ลูกค้าเลือก แล้วใส่ค่ายขนส่ง + เลขพัสดุในไทย
- แดชบอร์ดนับพัสดุตามช่วง + ค้นหา (เลขแทรคกิ้ง/ลูกค้า/เลขตู้/สินค้า)

**ความปลอดภัย**
- รหัสผ่านเก็บแบบเข้ารหัส (`password_hash` / bcrypt) — แอดมินก็มองไม่เห็นรหัสลูกค้า
- ใส่รหัสผิด 5 ครั้ง ล็อก 15 นาที
- เปลี่ยน/รีเซ็ตรหัสแล้ว เครื่องอื่นที่ล็อกอินค้างไว้จะถูกออกจากระบบ
- ป้องกัน CSRF ทุกฟอร์ม, SQL ใช้ prepared statements, ลูกค้าเห็นได้เฉพาะพัสดุของตัวเอง

## ติดตั้งบน Hostatom (หรือ shared hosting อื่น)

1. **สร้างฐานข้อมูล MySQL** ในแผงควบคุม (DirectAdmin/cPanel → MySQL Management)
   จดชื่อฐานข้อมูล, ชื่อผู้ใช้, รหัสผ่าน
2. **อัปโหลดไฟล์ทั้งหมด** ขึ้นโฟลเดอร์ `public_html` (ผ่าน File Manager หรือ FTP)
   หรือ `git clone` ถ้าโฮสต์มี SSH/Git
3. คัดลอก `config.sample.php` เป็น **`config.php`** แล้วแก้:
   - `db_host`, `db_name`, `db_user`, `db_pass` ตามข้อ 1
   - เรท/ค่าส่ง/เบอร์/LINE/ลิงก์ Facebook ตามจริง
4. เปิดเว็บ `https://โดเมนของคุณ/install.php`
   → ระบบสร้างตารางให้อัตโนมัติ → ตั้งชื่อผู้ใช้/รหัสผ่าน **แอดมินคนแรก**
5. **ลบไฟล์ `install.php`** ออกจากโฮสต์
6. เปิด SSL (Let's Encrypt) ในแผงควบคุม แล้วเอา `#` ออกหน้า 3 บรรทัด "force HTTPS" ใน `.htaccess`
7. ตั้ง PHP เป็นเวอร์ชัน **8.1 ขึ้นไป** (แผงควบคุม → PHP Selector)

### ใช้งานประจำวัน
1. ลูกค้าใหม่ → เมนู **ลูกค้า** → สร้างบัญชี → กด **คัดลอก** ข้อความแล้วส่งทาง LINE
2. ของเข้าโกดังญี่ปุ่น → กด **+ เลขแทรคกิ้ง** ที่แถวลูกค้านั้น → ใส่รายละเอียด
3. ของเคลื่อนที่ → เปิดพัสดุ → **อัปเดตสถานะ** (ระบบเลือกสถานะถัดไปให้)
4. ของถึงโกดังไทย → ลูกค้าเลือกขนส่งเอง (มีป้าย NEW ในหลังบ้าน) → ใส่เลขพัสดุไทย → อัปเดตเป็น "ส่งต่อให้ขนส่งในประเทศแล้ว"
5. ลูกค้าลืมรหัส → **รีเซ็ตรหัส** → ส่งรหัสใหม่ให้ (เข้าแล้วต้องตั้งใหม่อีกครั้ง)

## ปรับแต่ง

| ต้องการแก้ | ไฟล์ |
|---|---|
| เรท, ค่าส่ง, เบอร์, LINE, Facebook | `config.php` |
| ราคาเหมาสินค้าชิ้นใหญ่ | `inc/lang.php` (ส่วน `$BULK_PRICES` ท้ายไฟล์) |
| ข้อความบนเว็บ (ไทย/อังกฤษ) | `inc/lang.php` |
| สถานะการขนส่ง / รายชื่อขนส่งไทย | `inc/bootstrap.php` (`STAGES`, `CARRIERS`) |
| สี / ฟอนต์ / หน้าตา | `assets/style.css` |
| โลโก้ / รูปโกดัง | `assets/logo.jpg`, `assets/logo-sm.jpg`, `assets/warehouse.jpg`, `assets/container.jpg` |

## ทดสอบในเครื่อง (ไม่ต้องมี MySQL)

```bash
cp config.sample.php config.php   # แล้วแก้ db_driver เป็น 'sqlite'
php -S localhost:8000
# เปิด http://localhost:8000/install.php
```

## โครงสร้างไฟล์

```
index.php             หน้าแรก
login.php / logout.php
change_password.php   เปลี่ยนรหัส (บังคับครั้งแรก)
account.php           พัสดุของลูกค้า + รายละเอียด + เลือกขนส่ง
admin.php             หลังบ้าน: รายการพัสดุ
admin_customers.php   หลังบ้าน: บัญชีลูกค้า
admin_shipment.php    หลังบ้าน: ลง/แก้แทรคกิ้ง อัปเดตสถานะ
install.php           ติดตั้งครั้งแรก (ลบหลังใช้)
inc/                  โค้ดส่วนกลาง + ภาษา (ห้ามเข้าจากเว็บ)
assets/               CSS + รูป
data/                 ไฟล์ SQLite (ใช้ตอนทดสอบเท่านั้น)
```
